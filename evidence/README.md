# Evidências de execução

As evidências de execução dos testes (prints, vídeos e relatórios) podem ser geradas automaticamente via Playwright.

## 🔹 Execução local

Ao rodar os testes, o Playwright gera automaticamente:

- Screenshots em caso de falha
- Vídeos das execuções
- Trace para debugging

Comando:

npx playwright test
